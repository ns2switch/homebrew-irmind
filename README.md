# IRMind Homebrew tap

Packaging for the prebuilt [IRMind](https://github.com/ns2switch/irmind) terminal
incident-response assistant and its matching isolated EVTX helper on macOS and
Linux. See the [verified release installation guide](https://github.com/ns2switch/irmind/blob/main/docs/platforms.md).
